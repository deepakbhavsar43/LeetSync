LeetSync Settings

One-time setup. Talks straight to GitHub \u2014 no middleman ever sees your code or token.

How this stays private

This extension calls api.github.com directly from your browser using a token only you generate and hold. There is no server run by anyone else in the middle \u2014 nothing to trust beyond GitHub itself.

  1. On GitHub: Settings \u2192 Developer settings \u2192 Personal access tokens \u2192 Fine-grained tokens \u2192 Generate new token.
  2. Under "Repository access", choose "Only select repositories" and pick just the one repo you want solutions pushed to.
  3. Under "Permissions" \u2192 "Repository permissions", set Contents: Read and write. Leave everything else as "No access".
  4. Paste the token above. It's saved only in this browser's local extension storage on this device.
